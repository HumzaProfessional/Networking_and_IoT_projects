

### Goal of project
- This projects aims to create a  partitioned wireless sensor network (WSN) architecture with Zigbee-based local communication between sensor nodes and a cluster head within each crop zone.

  ### What's the purpose of this project
  - This project aims to tackle a major issue on the agcrifuclte industry based on pre-exisitng research and explored solutions. Agrucultre is an environmetnal costly industry. Likewise, the environment also greatly affects the environment.

- There are three layers to the WSN:
  - A zigbee power sensor network divide by paritiion by crop type and irrigation zone.
    - Here there will be a misocontroller deployed collecting data from sensors.
    - Each micorontroller will have a Zigbee module
    - There will a a cluster-head in head crop 
  - A gateway layer in the middle that serces to extend the retieved data tp the main cloud server.
  - The cloud is the third and top most layer.
    - This is where the main processing and storage happens
