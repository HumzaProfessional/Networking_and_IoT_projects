## Purpose

To capture packet data and analyze the content. Use regular expression to classify packet data into type classes.

## Goal

- Implement a regex parser.
- Convert regex -> NFA.
- Convert NFA -> DFA.
- Minimize the DFA.
- Feed it real or synthetic network-event streams.
- Measure throughput, memory usage, and number of states.
- Compare DFA versus NFA execution
